1. **CFAD 评测纪律**：CFAD 2000 只能评测，不可入训练（否则 EER 数字失效）；
2. **红队禁入训练**：红队 5238 仅作评测难例，训练只能用 FMFCC/aishell 等合规数据；

4. FMFCC 文件名数字命名（2000xxxx.wav）与标注表严格一致（key 含 .wav），协议转换勿去后缀。
