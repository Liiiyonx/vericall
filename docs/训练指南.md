## 三、训练命令

```bash
cd C:/Users/Liii/Desktop/谛听VeriCall/external/aasist
%PY% main.py --config C:/Users/Liii/Desktop/谛听VeriCall/configs/AASIST_5060.conf
```

`AASIST_5060.conf` 相对官方默认的改动及原因：

| 参数 | 官方 | 本机 | 原因 |
|---|---|---|---|
| batch_size | 24 | **14** | 8GB 显存安全值；若 OOM 降到 10，若有富余可试 16 |
| cudnn_benchmark | False | **True** | 固定输入长度时开启可提速 10-20% |
| cudnn_deterministic | True | **False** | 与上一条配套（复现实验时再改回 True） |
| database_path | ./LA/ | **D:/VeriCall_data/...** | 数据在 D 盘 |
| model_path | AASIST.pth | **AASIST_5060.pth** | 与官方预训练权重区分开 |

**显存预算参考**：AASIST 输入 4 秒原始波形（64600 样本），batch 14 时约 6-7GB。
笔记本 GPU 注意散热——长时间训练建议垫高散热、插电源、性能模式。

## 四、训练产物与指标

- 权重：`models/weights/（在 external/aasist 下）AASIST_5060.pth`（每个 epoch 存 best）
- 日志：`external/aasist/models/tensorboard/`（`tensorboard --logdir` 查看）

## 六、常见坑

| 症状 | 解法 |
|---|---|
| `CUDA error: no kernel image` | torch 装成了 CPU 版或旧 cu 版；必须 cu128（sm_120） |
| OOM | batch 降 10；或 nb_samp 降到 32000（2 秒）先跑通 |
| dataloader 卡死 | Windows 下 num_workers 默认 0 就好，别调大 |
| pip 下载龟速 | 清华镜像装普通包；CUDA torch 只能走官方源（后台挂着） |

## 七、已对 AASIST 官方基线做的兼容修改（重要，勿回滚）

本机是 numpy 2.x + 沙箱环境，官方 clovaai/aasist 代码（numpy 1.x 时代）需以下修补才能跑：

1. **`external/aasist/evaluation.py`**
   - `calculate_tDCF_EER` 增加 **EER-only 分支**：当 `asv_score_file` 缺失/不存在时，
     跳过 t-DCF，只算 CM 的 EER 并返回 `(eer, None)`。原因：本项目没有外部 ASV 系统的
     分数文件（LA.zip 不含 asv_scores），原代码会因缺文件直接崩溃。
   - 3 处 `np.float` → `float`（numpy 2 已删除该别名）。

2. **`external/aasist/main.py`**
   - 所有使用 `dev_tdcf` / `eval_tdcf`（可能为 None）的地方加 None 守卫，避免
     `format(None)` 与 `min(None, ...)` 崩溃；`best_dev_tdcf/best_eval_tdcf` 初值改为 None，
     日志/打印对 None 输出 `N/A (no ASV scores)`。

3. **冒烟测试**：`scripts/smoke_train_aasist.py` 用合成音频构造极小数据集跑 1 epoch，
   验证「数据加载→前向→损失→EER」整条管线。已通过（Device=cuda，退出码 0）。

> 复现结论：本机 RTX 5060 + cu128 下 AASIST 训练管线**已端到端跑通**，只差真实 ASVspoof 数据。
