# 谛听 VeriCall · 适老模式测试记录（P2-3 验收用）

> 功能已实现（大字模式 + 红黄绿整屏色块 + 语音播报 + 非指控式文案库 `web/copy.js`）。
> 本表用于记录 3 位 60+ 长辈的真实试用结果，是《试点使用报告》的前身。

## 测试协议（每人 10–15 分钟）

1. 打开顶栏「适老」开关 → 确认字体变大、实时页出现整屏色块。
2. 实时监测页播放一段诈骗话术 → 观察：能否看懂绿→黄→红、是否听到语音播报、能否复述建议动作。
3. 触发一次告警 → 点「发给子女」→ 观察：能否理解分享卡片内容。
4. 故意制造一次"误拦"（正常家人聊天被标黄）→ 记录情绪反应。
