## 一、通道① 声学防伪：从单模型到「多模型融合 + 全频谱防御」

**现状差距**：单 AASIST、仅英文 ASVspoof19 训练、整段中心裁剪（已修）、跨域与中文能力零验证。

**极致举措**：

1. **模型矩阵（不再单点）**：
   - 主力：AASIST 继续作为可复现基线（保留现有 EER 证据链）；
   - 增量 1：**SSL 大模型前端**（wav2vec2-XLS-R 300M / WavLM）+ AASIST 后端——这是近年 ASVspoof 冠军方案的标准结构，不计算力下必上；
   - 增量 2：RawNet2 / RawGAT-ST 作为第三路异构模型；
   - 三路输出做**分数级融合**（logistic  stacking，权重在 dev 集学习）。
2. **训练数据全量放开**（详册已核实获取路径）：
   - 英文：ASVspoof 2019LA/2021LA/5 + WaveFake 全量（约 11.8 万）+ MLAAD 中文子集 + In-the-Wild（仅评估）；
   - 中文：FMFCC-A（1万真/4万伪）+ CFAD（3.86万/7.72万）+ 红队自制（见第四节）；
   - 增强：MUSAN 全库加噪 + **电话信道仿真**（8kHz 重采样、AMR/Opus/G.711 编解码循环、P.341 滤波）——直接把「电话诈骗」场景写进训练分布。
3. **部分伪造定位**：用 PartialSpoof 训练窗口级分支，输出「哪一段是假的」——与流式 3s 滑窗天然契合，也是论文级贡献点。
4. **工程加速**：多卡 DDP 训练、混合精度、实验管理接 Weights & Biases（不计成本：云 A100×4 按需）。

**验收**：eval EER<1.5%（19LA）；CFAD/FMFCC-A 跨域 EER<5%；电话信道条件下 EER 退化 <3 个百分点；窗口级定位 AUC≥0.9。

**时间**：2026.09 下–2026.11（与 P1 并行，v0.5-streaming 内含第一版双模型融合）。

## 二、通道② 声纹核验：从「能跑」到「家庭场景可信」

**现状差距**：CAMPPlus 单模型、阈值 0.55/0.35 拍脑袋、声纹库内存态、无防攻击设计。

**极致举措**：

1. **模型升级**：CAMPPlus 保留为轻量线，新增 **ERes2Net / 3D-Speaker** 大模型做高精度线（注册比对走离线大模型，实时窗走轻量线）。
2. **阈值科学标定**：千人级公开底库（AISHELL-3 全 218 人 + VoxCeleb 子集）扫描 DET 曲线，按「家庭场景误拒代价 >> 误受代价」定工作点，全部写进实验报告。
3. **防攻击三板斧**：
   - 防录音回放：Challenge-Response（随机数字串跟读）+ 回放检测子模型；
   - 防 TTS/VC 冒充：直接复用通道①防伪分数做门控（两通道天然互相加固，这是架构级卖点）；
   - 防跨信道失配：注册时强制「安静室内 + 电话免提」双信道采集（详册 §4.3 协议已定义）。
4. **声纹库工程化**：加密落盘（嵌入向量非原始音频）、可撤回、仅存本地——合规即卖点。

**验收**：千人底库 EER<2%；回放/TTS 攻击拦截率 ≥95%；双信道注册后跨信道 EER 退化 <50%。

**时间**：2026.10–2026.12。

## 三、通道③ 语义分析：从「8B 本地小模型」到「大小模型协同 + 知识库」

**现状差距**：r1:8b 单模型、话术库为零散收集、无多轮上下文、无校准。

**极致举措**：

1. **万级中文话术库（一切的地基）**：
   - 来源：国家反诈中心通报、裁判文书网判决书、主流媒体披露剧本（详册 §5 已定脱敏红线）；
   - 扩增：**不计成本用大模型 API**（DeepSeek/GPT 级）做角色扮演变体（称谓/金额/紧迫度/方言口语化），目标 **10,000+ 条**，人工抽检 ≥20%；
   - 标注体系：诈骗类型 × 话术阶段（寒暄/铺垫/紧迫/要钱）× 风险要素（账户/验证码/转账）。
2. **双模型推理架构**：
   - 实时线：本地小模型（qwen2.5:3b / r1:1.5b）每 5s 节流快筛（沿用 P1-1 修复后的节流器）；
   - 深评线：**云端旗舰模型 API**（强推理 + 长上下文）做多轮研判与拦截后复盘报告——不计成本后，「8B 卡实时」的妥协直接解除；
   - 专用微调：用万级语料 LoRA 微调 Qwen2.5-32B 做「诈骗话术分类专才」，与通用大模型互为冗余。
3. **RAG 反诈知识库**：判决案例向量化入库，LLM 研判时检索相似真实案例作为依据——输出「像 2023 年 XX 案」的可解释理由，适老文案直接受益。
4. **置信度校准**：深评输出做温度标定，避免 LLM 分数不可比。

**验收**：万级语料库 + 标注规范文档；测试集 F1≥0.95；多轮（≥5 轮）上下文研判准确率 ≥90%；复盘报告人工评审优良率 ≥90%。

**时间**：2026.09 下启动语料建设（时间瓶颈，最先开工），2026.11 完成双模型架构，2026.12 微调专才模型。

## 四、红队对抗体系：从「三个工具」到「伪造语料工厂 + 红蓝循环」

**现状差距**：GPT-SoVITS/CosyVoice/Seed-VC 仅核实了获取方式，未产一条语料。

**极致举措**：

1. **伪造语料工厂（不计算力的最大受益者）**：
   - 三套 TTS/VC × 多说话人 × 多话术 × 多信道（干净/电话/免提/噪声）网格化批量合成，目标 **≥50,000 条**；
   - 方言版：志愿者录音（任务书 P2-1 已启动招募）+ 方言 TTS，目标方言子集 **≥5,000 条**（川渝/粤语/东北/江浙优先）；
   - 质量门禁：MOS≥3 抽检 + 通道①反向筛选（防伪模型高置信漏检样本优先入库——难例挖掘自动化）。
2. **对抗攻击实验**：对自有模型做白盒/黑盒对抗扰动评估（FGSM/PGD 级），产出「攻击—防御—再攻击」的迭代记录，这是信安赛道的核心叙事。
3. **红蓝循环机制**：每轮红队新攻击入库 → 模型增量训练 → 出 EER 变化曲线，形成可持续的「攻防演化图」（论文与 PPT 的王牌图）。
4. **物理隔离纪律**：红队集禁入训练管线（详册 §7.3 已定），每次评估前跑隔离检查脚本。

**验收**：5 万条语料 + 元数据完整（meta.csv 字段按详册 §7.2）；攻防演化图 ≥3 轮迭代；红队集对自有模型的首轮「击穿率」与修复后对比数据。

**时间**：2026.09 启动（招募与合成并行），2026.12–2027.02 产出主体（v0.8-redteam）。

## 五、流式引擎与产品化：从「能演示」到「敢给老人用」

**现状**：P1-1 三项修复已完成（尾窗采样率/LLM 节流/模型常驻），声学 0.03s/次，66/66 测试绿。

**极致举措**：

1. **延迟压到 500ms**：三通道从串行改**并行调度**（GPU 常驻后算力允许）、AASIST/CAMPPlus 导出 ONNX/TensorRT、SenseVoice 流式热词；目标 P90 ≤500ms/窗。
2. **适老交互做到极致**：
   - 大字模式 + 三色大圆环（已有 `.orb` 动画基础）；
   - **TTS 语音播报拦截理由**（本地 TTS，语速放慢）；
   - 一键「回拨核实」按钮（直接拨打子女）；
   - 方言播报选项。
3. **子女端联动**：微信小程序/轻 App——拦截事件推送、远程查看周报、协助标定声纹。
4. **部署形态双轨**：本地一体机（隐私优先，数据不出户）+ 云端分析版（不计成本，推理上云 GPU）——答辩时讲「隐私与性能的可选权衡」。
5. **试点**：2 个社区/养老驿站试点，按《试点使用报告模板》回收真实反馈 ≥30 份。

**验收**：P90 ≤500ms；60 岁+ 用户无指导完成率 ≥80%；试点报告 2 份。

**时间**：2026.11 延迟优化，2026.12–2027.02 适老与子女端（v0.8 尾部），2027.03 试点。

## 六、评测与工程基建：从「66 个测试」到「可审计的质量体系」

1. **`evaluation/` 从零建成 benchmark 套件**：跨域矩阵（训练集 × 评估集全组合）、信道矩阵（干净/AMR/Opus/免提）、攻击矩阵（红队各代）、适老场景集；一键输出参赛级 PDF 报告（图表自动生成，直接进 PPT）。
2. **MLOps**：W&B 实验追踪 + DVC 数据版本 + 模型 registry（每个 EER 数字可回溯到代码 commit + 数据版本 + 配置）。
3. **CI 加固**：每周全链路回归（三场景门控）+ GPU 冒烟 + 流式回放测试（`test_streaming.py --replay`）进 CI；测试覆盖率 ≥80%。
4. **安全自查清零**：路径穿越、innerHTML 注入、`.gitignore` 家人录音保护（任务书 §1.3 短板 9/11/12）——信安赛道自身不能有洞。
5. **合规材料**：知情同意书全流程电子化签署、数据伦理自查表、许可证汇总（详册 §8.1 已起步）。

**验收**：`evaluation/` 一键报告；W&B 全实验可溯；CI 周报告连续 8 周绿。

**时间**：2026.10 启动，贯穿全程。
