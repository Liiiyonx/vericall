## 录制清单（开拍前 10 分钟自检）

- [ ] 服务起得来：`start.bat`（Windows）或 `bash start.sh`（Linux/macOS）。
- [ ] 降级保底已验证：`VERICALL_OFFLINE=1` 下三场景 A=放行 / B=拦截 / C=警惕 全部成立。
- [ ] 实时页麦克风权限已授权；诈骗话术脚本打印在手边（避免临场卡壳）。
- [ ] 红队报告截图取最新一份（`evaluation/reports/redteam_text_*.md`）。
- [ ] 适老模式 `elder-mode` 开关可一键切换。

## 不可剪辑承诺

所有"实时变红"镜头均为真实系统运行结果，不加速、不摆拍。若现场环境异常，启用 P0-4 降级模式仍可复现完整演示链路，确保答辩不翻车。
