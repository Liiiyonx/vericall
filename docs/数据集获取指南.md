# 数据集获取指南（谛听 VeriCall）

> 规模数字已与官方论文及 ACM Computing Surveys 语音深度伪造综述（2025）交叉核实。

## 优先级 P0 —— 第一周就要动手

### 1. ASVspoof 系列（核心训练集，需注册审核，周期数天）
官网：https://www.asvspoof.org/
- **ASVspoof 2019 LA**：12,483 真 / 108,978 假，19 种 TTS/VC 攻击，16kHz flac。基线复现首选。
- **ASVspoof 2021 LA**：18,452 真 / 163,114 假，含传输信道扰动。
- **ASVspoof 2021 DF**：22,617 真 / 589,212 假，100+ 编解码攻击。
- **ASVspoof5（2024）**：188,819 真 / 815,262 假，28 种攻击，含嘈杂/远场/对抗样本。**最贴近电话信道场景。**
- 获取：官网填表注册 → 邮件审核 → 下载链接。⏰ 先申请，等审核期间做别的。

### 2. WaveFake（GitHub 直接下载，今天就能跑）
- 117,985 假样本（175 小时），英/日，6 种 GAN-TTS（MelGAN、HiFi-GAN、WaveGlow 等）。
- 仓库：https://github.com/rub-senshi/WaveFake

## 优先级 P1 —— 中文能力与泛化评测

### 3. FMFCC-A（中文）
- 10,000 真 / 40,000 假，含噪声与编解码，16kHz wav。中文基线的起点。

### 4. CFAD（2024，中文）
- 38,600 真 / 77,200 假，12 种 TTS/VC 生成方法，含噪声场景。

### 5. MLAAD（2024，多语言）
- 76,000 假语音，23 语言 × 54 种 TTS。跨语言泛化评测用（我们主测中文方向）。

### 6. In-the-Wild（2022，视频+音频真实场景）
- 19,963 真 / 11,816 假，YouTube 真实场景。**跨域评测金标准**：英文干净数据训出的模型在此普遍大幅劣化——把劣化量化出来就是我们的研究素材。

## 优先级 P2 —— 二期视频线（换脸检测）

- **FakeAVCeleb**：570 真视频 / 25,000 假，音视频双模态伪造（申请制）。
- **FaceForensics++**：1,000 真 / 5,000 假视频，4 种篡改算法（注册制）。
- **DFDC**：约 12.8 万视频（注册制，Meta）。
- **Celeb-DF v2**：590 真 / 5,639 假，画质高、最难检测之一。

## 自建：红队方言评测集（数据壁垒，伴随全程滚动采集）

| 项 | 说明 |
|---|---|
| 真实样本 | 自愿者及家人：普通话 + 方言（福州话等）各 5 分钟，电话信道/免提/安静环境三档录音 |
| 伪造样本 | GPT-SoVITS / CosyVoice / Seed-VC 等开源模型对上述声纹做零样本/微调克隆 |
| 信道仿真 | 8kHz 电话降采样、AMR 编解码、免提混响、加噪 |
| 伦理 | 知情同意书（docs/ 提供模板），仅研究评测用，不外传 |

## 预处理统一约定

- 采样率：16kHz 主线 + 8kHz 信道仿真分支
- 切分：4 秒段（滑窗 50%），部分伪造实验用词级标注
- 格式：wav / flac 统一转 wav；目录按 `data/raw/<dataset>/{bonafide,spoof}/`
- 划分：严格按官方 train/dev/eval，跨域实验另建协议文件
