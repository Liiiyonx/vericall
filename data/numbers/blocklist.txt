# 公开涉诈号码库（用户维护，本模块不内置实号）

- 格式：每行一个号码；`#` 开头为注释；可选 `号码<TAB>备注[<TAB>来源]`。
- 建议来源（公开源，不碰付费私有库）：
  - 12321 网络不良与垃圾信息举报受理中心公开通报样本；
  - 运营商对自有用户的骚扰/诈骗标记（经合法授权导出后脱敏）；
  - GitHub 开源骚扰/诈骗号码黑名单仓库（接入前核对许可证与数据可信度）。
- 参考接入命令（下载某个公开列表到本文件或独立文件，再设
  `VERICALL_NUMBER_BLOCKLIST=绝对路径` 指向它）：
  ```bash
  curl -L -o data/numbers/blocklist.txt https://<公开源raw-url>   # 请自行替换为可信源
  ```
- 本模块只做"接入 + 查表"，命中即先验拦截；号码库的更新策略由数据源决定。
