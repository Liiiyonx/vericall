- **修复结果**：pip check 零缺失零冲突；pytest **66/66 全绿**；torch 2.8.0+cu128 CUDA True；numpy 1.26.4（从 2.2.6 降回，适配 funasr 声明约束）；opencv-python 降回 4.10.0.84（4.13 要求 numpy≥2）。

- **两个关键坑（复修必读）**：
  1. `pip install --force-reinstall` 会被**安全删除钩子**拦截（`OSError: SHFileOperationW 失败: 0x2`）——pip 内删文件被钩子接管失败。**正确做法：先手动 `rm -rf` 空壳 dist-info/残留包目录（shell 删除不受钩子拦截），再用普通 `pip install`（只写不删）**。
  2. 直连 PyPI 极慢（21 分钟未完成），**必须挂镜像** `-i https://pypi.tuna.tsinghua.edu.cn/simple`（同批 38 秒完成）。
- **排查手法**：`pip check` 列缺失 → 循环扫描 `for d in site-packages/*.dist-info; [ -f METADATA ] || 空壳` → 手动清空壳 → 逐包/批量普通安装 → pip check 复检 → pytest 认证。
- **根因未除**：Defender `ExclusionPath` 仍为空（需管理员权限手动加排除：`C:\Users\Liii\.conda\` 与 `D:\VeriCall_data\`）；未加前环境仍有再被破坏风险。若装的是第三方杀软（360/火绒等），需在其白名单中等效添加。
