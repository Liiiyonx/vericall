## 一、触发时机（产品语义）

系统在以下任一条件满足时，播报随机 4 位数字串要求对方跟读（`challenge_response.py`）：
1. 通道①声学伪造分「存疑」（0.5 ≤ score < 0.85）；
2. 通道②声纹相似度「低置信」（< 0.520 且 > 0.443）；
3. 大额转账操作前（金额阈值可由子女端配置）。

## 二、回放设备与攻击场景定义

| 设备代号 | 回放方式 | 说明 |
|---|---|---|
| D1 | 录音机/另一手机录后外放 | 最典型：骗子录下家人声音，通话中外放 |
| D2 | 电脑/平板音箱外放 | 高保真外放，失真较小 |
| D3 | 耳机贴麦克风复读 | 绕过扬声器-麦克风失真，最难防（靠数字匹配层拦截） |

| 场景代号 | 攻击方式 | 预期拦截机理 |
|---|---|---|
| R1 | 全量录音回放（整段诈骗话术） | 数字不匹配（录音无法跟读新随机串） |
| R2 | 固定跟读回放（预录"跟读"但数字是旧串） | 数字不匹配 |
| R3 | 剪接回放（多段拼接） | 数字不匹配 / 音色不连续 |
| R4 | 换人代读（同伙实时代读） | 音色不匹配（CAMPPlus 相似度 < 0.520） |
| R5 | 本人实时跟读（正常对照） | 数字 + 音色双匹配 → 放行 |
