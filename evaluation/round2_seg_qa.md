## 一、方法

对每条样本做音频结构健康筛查（soundfile 读 wav，20ms 帧 RMS 语音检测）：

| 指标 | 阈值 | 含义 |
|---|---|---|
| 整段时长 | ≥1.0s | 过短段信息量可疑 |
| 有效语音量 | ≥0.7s 且占比 ≥35% | 静音过多疑切坏/内容稀 |
| 整段 RMS / 峰值 | ≥-42.0 / ≥-36.0 dBFS | 音量异常 |
| 硬削波占比 | ≤5e-04 | 重编码/限幅伪影 |
| 首/尾静音 | ≤0.6s / ≤0.9s | 切点含大段空白 |

> 说明：本报告为**机器预筛**，verdict=pass_struct 仅代表结构健康，仍需耳听抽查；verdict=suspect 的段建议人耳终审（听判切坏/静音/过短），必要时 drop。
