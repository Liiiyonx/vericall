## 二、加速策略（保证质量的三条铁律 + 三条加速杠杆）

### 铁律（质量不妥协）
1. **每个数字可复现**：脚本进 `evaluation/`，评委复算不出 = 没做。
2. **红队隔离纪律**：红队 5238 禁入训练；CFAD 仅评测；每次评估前跑隔离检查。
3. **数据合规优先**：红队无授权不入库；话术原文不脱敏不出库；敏感信息不进 git。

### 加速杠杆（省时间不省质量）
1. **砍锦上添花**：暂停「32B 话术专才微调」「ERes2Net 大模型声纹线」等非验收必需项，先保下限。
2. **并行 + 错峰**：人工项（语料复核、白名单）与可自动项（红蓝第 2 轮、评测补全）并行推进，不等人工。
3. **人工依赖前置暴露**：把需要人做的事列成"最小人工清单"，一次性交付，避免零散等待。

## 五、质量门禁（每个阶段结束时必过）

1. **回归绿**：`pytest tests/ -q` 全绿（当前 65 项，每新增功能补测试）。
2. **隔离检查**：红队/CFAD 未混入训练脚本。
3. **可复现**：新增数字都有对应 `evaluation/*.py` + 报告 md。
4. **双环境同步**：主仓 + worktree 台账同步，不留漂移。
5. **评委视角走查**：每阶段末用"拿掉作者滤镜"视角查一遍叙事是否自洽（尤其评测域匹配原则、攻防演化口径）。
