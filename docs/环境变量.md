# 谛听 VeriCall · 环境变量速查

所有绝对路径集中在 `src/paths.py`，解析优先级：**进程环境变量 > 项目根 `.env` > 代码默认值**。
复制模板：`cp .env.example .env` 后按需修改。

| 变量 | 含义 | 默认值 |
|---|---|---|
| `VERICALL_DATA_ROOT` | 数据集 / 模型 / 日志根目录（大文件，默认 D 盘） | `D:/VeriCall_data` |
| `VERICALL_MODELS_ROOT` | 模型目录 | `$DATA_ROOT/models` |
| `VERICALL_ASVSPOOF_LA` | ASVspoof2019 LA 解压目录 | `$DATA_ROOT/ASVspoof2019_LA/LA` |
| `VERICALL_LA_ZIP` | ASVspoof LA 压缩包路径 | `$DATA_ROOT/LA.zip` |
| `VERICALL_PARQUET_DIR` | parquet 数据集目录 | `$DATA_ROOT/parquet` |
| `VERICALL_SMOKE_ROOT` | 冒烟测试迷你数据集 | `$DATA_ROOT/smoke_ASVspoof2019_LA` |
| `VERICALL_SENSEVOICE_DIR` | SenseVoiceSmall 模型目录 | `$MODELS_ROOT/SenseVoiceSmall` |
| `VERICALL_OLLAMA_HOST` | （已弃用）仅 `VERICALL_SEMANTIC_LLM=ollama` 逃生口用 | `http://localhost:11434` |
| `VERICALL_OLLAMA_MODEL` | （已弃用）同上 | `deepseek-r1:8b` |
| `VERICALL_SEMANTIC_LLM` | 话术语义 LLM 后端：`cloud`（默认，DeepSeek 云端）\| `ollama`（太慢，仅显式开） | `cloud` |
| `VERICALL_AASIST_DIR` | clovaai/aasist 代码目录 | `$ROOT/external/aasist` |
| `VERICALL_AASIST_EXP` | AASIST 实验名 | `LA_AASIST_5060_ep24_bs16` |
| `VERICALL_TRAIN_LOG` | 训练日志路径 | `$DATA_ROOT/training_ep30.log` |
| `VERICALL_BENCH_LOG` | 基准测试日志 | `$DATA_ROOT/bench.log` |
| `VERICALL_PID_FILE` | 训练进程 PID 文件 | `$DATA_ROOT/train_pid.txt` |
| `VERICALL_DEVICE` | 推理设备 | `cuda` |
| `VERICALL_PORT` | 演示 API 端口 | `8000` |
| `VERICALL_OFFLINE` | 离线降级模式（1=开） | `0` |

## 极致化计划新增（2026-09-03）

| 变量 | 含义 | 默认值 |
|---|---|---|
| `SCAM_LLM_BASE` | 云端 DeepSeek 的 OpenAI 兼容端点（2026-09-06 起默认后端，不设则用官方端点） | `https://api.deepseek.com/v1` |
| `SCAM_LLM_KEY` | 云端 LLM API Key（**不入库**，见下方密钥存放约定；缺 key 不静默回退 ollama，给明确报错/规则兜底） | 空 |
| `SCAM_LLM_MODEL` | 云端模型名（如 `deepseek-chat`） | `deepseek-chat` |
| `OLLAMA_URL` / `OLLAMA_MODEL` | （已弃用）话术库/语义本地后端，仅显式选择时启用 | `http://localhost:11434` / `deepseek-r1:8b` |

涉及脚本：`scripts/scam_corpus/build_corpus.py`、`build_benign.py`、`generate_scam_scripts.py`、`src/fusion/semantic_channel.py`——**默认一律云端 DeepSeek**（缺 `SCAM_LLM_KEY` 即报错提示 source secrets，或由语义通道走规则评分兜底）。

**密钥存放约定（2026-09-04 起，用户要求）**：敏感信息/账户凭据**不放 C 盘**——不写项目 `.env`、不写注册表。统一存 `D:\VeriCall_data\secrets\vericall_secrets.env`（变量带 `export`）；跑脚本前 `source` 该文件即可，例如：
```bash
set -a; source "D:/VeriCall_data/secrets/vericall_secrets.env"; set +a
python scripts/scam_corpus/build_corpus.py --append --backend cloud
```
