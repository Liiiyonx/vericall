## 3. 四个"能讲"的结论（评委必问，提前备好）

1. **真实 EER 硬**：通道① eval 3.49%，远超多数 PPT 项目（多数无真实训练）。
2. **实时叙事兑现**：3s 滑窗与 AASIST 输入对齐 → 零改造流式；P90 延迟 ≤2s，绿→黄→红可现场复现。
3. **我们攻击过自己**：红队方言评测暴露粤语/闽南 100% 漏拦 + 对抗逃避率最高 100%，引出"文本归一化 + 语义向量检测"改进路线（诚实讲局限 = 研究深度）。
4. **适老零误伤**：红队误拦率 0%，降级模式保底答辩不翻车。

## 4. 工程完整度（作品 vs demo 的分水岭）

- 路径配置化：6 处 `D:/` 硬编码清零，环境变量 > `.env` > 默认值（`src/paths.py`）。
- 一键启动：`start.bat` / `start.sh`，自动装依赖、探测 Ollama、缺失则降级。
- 声纹持久化：落盘 `data/voiceprints/`，重启不丢，多样本平均更稳。
- 测试 + CI：47 项 pytest 纯逻辑全绿；`.github/workflows/pytest.yml` 双版本 Python 回归。
- 许可合规：MIT LICENSE；ASVspoof 数据禁止再分发 → 演示音频本地生成不入库；红队/试点数据签知情同意书、不入库。
- 适老交互：大字模式 + 红黄绿整屏色块 + 语音播报（`web/copy.js` 非指控式文案库，localStorage 记忆偏好）。
