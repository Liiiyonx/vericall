# 谛听 VeriCall · 社区试点方案与《试点使用报告》模板（P3-2）

> 用途：互联网+/红旅赛道"科技适老社会价值"的证据；同时也是真实用户反馈闭环。
> 经学校团委/社团对接 1 个社区或养老机构，目标 **10 户 × 2 周** 家用试用。

## 一、试点方案

### 1.1 招募与准入
- 对象：社区 60+ 老人家庭，每户至少 1 位常住老人 + 1 位子女（或监护人）作为联动方。
- 准入：签署《知情同意书》（`docs/知情同意书模板.md`），声明数据仅用于研究与产品改进、不外传。
- 配置：每户预登记 1–2 位家人的声纹（CAMPPlus，落盘持久化，重启不丢）。

### 1.2 试用流程（2 周）
- 第 1 天：上门安装 + 声纹登记 + 适老模式教学（大字/播报/子女卡片）。
- 日常：老人日常来电由系统后台检测（脱敏日志：来电时间、三通道证据摘要、结论）。
- 触发：出现黄/红事件 → 自动生成子女分享卡片（P2-4），子女端收到提醒。
- 第 14 天：回收满意度问卷 + 半结构访谈。

### 1.3 采集指标
| 指标 | 口径 | 用途 |
|---|---|---|
| 使用次数 | 累计检测来电数 | 活跃度 |
| 拦截事件 | 黄/红事件数 + 子女卡片送达数 | 有效性 |
| 误报反馈 | 老人/子女标记"误拦"次数 | 误拦代价（FA）实测 |
| 满意度问卷 | 5 题 Likert（易懂/可信/愿用/愿推荐/安全感提升） | 社会价值证据 |

## 三、合规红线（必读）
- 试点录音/日志仅本机存储，不入库 git（`.gitignore` 已排除 `data/`）。
- 论文/答辩中说话人匿名化，不出现真实姓名与可定位信息。
- 试点报告归项目所有，对外发布前经社区/机构知情同意。

> 注：本模板为"可立即执行"版本；真实试点需在数据到位、系统联调稳定后开展，
> 当前仓库已具备声纹持久化（P0-6）、适老模式（P2-3）、子女卡片（P2-4）三项前置能力。
